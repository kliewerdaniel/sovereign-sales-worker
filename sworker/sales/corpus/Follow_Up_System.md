# Follow-Up System

Deterministic cadence per pipeline stage. Sequences are the source of truth for
when the follow-up worker schedules the next action. Day 0 = same day as the
triggering event.

### New Prospect Sequence

Same day: Initial outreach email — short, evidence-based, one clear question.
Day 3: Follow-up #1 — reference the specific signal observed; one-line nudge.
Day 7: Follow-up #2 — offer a low-friction next step (audit teardown call).
Day 14: Follow-up #3 — close the loop; if no response, move to nurture.

### Discovery Completed Sequence

Same day: Send call summary + the audit proposal; thank them for their time.
Day 2: Check-in on the proposal; answer any open questions.
Day 5: Proposal nudge — restate the single highest-value finding.

### Proposal Sent Sequence

Day 3: Proposal follow-up — re-anchor on the quantified opportunity.
Day 7: Decision nudge — offer a working session to scope implementation.
Day 14: Final follow-up before marking stale; re-engage date set if no.
