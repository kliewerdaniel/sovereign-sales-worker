# Metrics — Single Source of Truth

All daily activity reports reference this file for target numbers. Every count is
re-derived from the ledger; if a daily minimum is not met, it is a failed sales
day.

## Daily Minimums

- 20 prospects researched
- 5 new outreach messages sent
- 10 follow-ups sent
- 2 discovery calls scheduled
- 1 discovery call completed

## Weekly / Pipeline Targets (guidance)

- At least 1 qualified opportunity moved to proposal per week
- Reply rate tracked; below 5% triggers message/offer review
- Stale-lead SLA breaches reviewed daily

If all not met -> Failed sales day. The daily brief surfaces the gap explicitly.
